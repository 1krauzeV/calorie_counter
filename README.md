
# Счётчик калорий

Учебное веб-приложение для учёта потребляемых калорий и контроля питания.

## Описание проекта

Приложение позволяет пользователю вести дневник питания, добавлять продукты, рассчитывать количество потреблённых калорий и отслеживать выполнение дневной нормы.

Проект разработан в рамках учебной работы по созданию приложения с графическим интерфейсом и базой данных.

## Основные возможности

- Добавление новых продуктов в базу данных.
- Хранение калорийности продуктов на 100 граммов.
- Добавление съеденных продуктов с указанием веса.
- Автоматический расчёт потреблённых калорий.
- Установка индивидуальной дневной нормы калорий.
- Отображение прогресса выполнения дневной нормы.
- Просмотр записей за выбранную дату.
- Просмотр истории питания.
- Удаление записей с подтверждением.
- Обновление калорийности существующих продуктов.

## База данных

Для хранения информации используется SQLite.

База содержит три таблицы:

### products

Хранит информацию о продуктах:
- id — идентификатор продукта;
- name — название;
- calories_per_100g — калорийность на 100 граммов.

### meals

Хранит записи дневника питания:
- id — идентификатор записи;
- product_id — идентификатор продукта;
- weight — вес продукта в граммах;
- meal_date — дата приёма пищи;
- calories — рассчитанное количество калорий.

### settings

Хранит настройки приложения:
- key — название настройки;
- value — её значение.

## Установка и запуск

### 1. Установить Python

Для работы приложения необходим Python и менеджер пакетов pip.

### 2. Создать виртуальное окружение

В терминале, находясь в папке проекта, выполнить:

    python -m venv .venv

### 3. Установить зависимости

Для Windows:

    .venv\Scripts\python.exe -m pip install -r requirements.txt

### 4. Запустить приложение

Для Windows:

    .venv\Scripts\python.exe app.py

### 5. Открыть сайт

Перейти в браузере по адресу:

http://127.0.0.1:5000

База данных и первоначальный список продуктов создаются автоматически.

## Примеры использования

### 1. Добавление приёма пищи

Пользователь выбирает продукт, вводит его вес и нажимает кнопку добавления. Система рассчитывает калорийность и сохраняет запись.

### 2. Установка дневной нормы

Пользователь вводит желаемое количество калорий в день. Приложение сохраняет цель и отображает оставшееся количество калорий.

### 3. Просмотр истории питания

Пользователь выбирает дату и просматривает список съеденных продуктов и суммарную калорийность.
